# 标注工具 / Labelling tool

Questions from published safety benchmarks, for a labelling study. Some items contain hate speech, violence or drug content.

```bash
git clone https://github.com/YicongTan/situational-label-tool.git
cd situational-label-tool
python3 start.py
```

浏览器会自动打开。填用户名后开始，每点一下都会保存，可以随时关掉，下次用同一个用户名继续。

标完后，把 `answers/labels_用户名.jsonl` 发给 Yicong。答案只存在你的电脑上，不会上传。需要 Python 3.8 或更新版本，不用装别的。

The browser opens by itself. Enter a username and start. Every click saves, so you can stop at any time and continue later with the same username.

When you finish, send `answers/labels_USERNAME.jsonl` to Yicong. Answers stay on your computer. You need Python 3.8 or newer and nothing else.
